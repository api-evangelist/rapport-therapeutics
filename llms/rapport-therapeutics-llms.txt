# Rapport Therapeutics

> Rapport Therapeutics, Inc. (Nasdaq: RAPP) is a clinical-stage biotechnology company in Boston, MA
> and San Diego, CA, developing precision small-molecule medicines for central nervous system
> disorders on its RAP technology platform. Rapport publishes no developer program, no public API and
> no machine-readable API contract; this file exists so agents can find the company's authoritative
> public pages and stop looking for an API surface that does not exist.

## APIs

- None. Rapport Therapeutics is a therapeutics developer, not a software vendor. As of 2026-08-26 no
  OpenAPI, Swagger, GraphQL, AsyncAPI, gRPC or WSDL contract is published on any Rapport host, and no
  developer, docs or api subdomain resolves.

## Science and Pipeline

- [Precision Neuroscience](https://www.rapportrx.com/precision-neuroscience/): The RAP technology
  platform — receptor-associated proteins that confer neuroanatomical specificity.
- [Pipeline](https://www.rapportrx.com/pipeline/): RAP-219 (TARP-gamma-8 negative allosteric
  modulator) in focal onset seizures, peripheral neuropathic pain and bipolar disorder; discovery
  programs on alpha-6 nAChR (chronic pain) and alpha-9-alpha-10 nAChR (hearing disorders).
